## Çalıştırılan senaryolar (en az 3 şartı)

1. `a.scn.ts`: gelmedi + bedel (kilitli gün), erken gelmedi reddi, iptal + iade (fazla, döviz, tam), çift iptal, iptal sonrası tahsilat, kısmen konaklamış çok odalı iptal + iade, depozito alma/iptal/gelire çevirme.
2. `b.scn.ts`: grup (toplu ödeme dağıtımı, atomik toplu çıkış, iptal, aynı odayı iki kez yazan grubun geri alınması), saatlik satış (bitişik, çakışan, 24:00, gece içi, çıkış günü), `undoCheckIn` (yetki, iptal + iade).
3. `c.scn.ts`: `undoCheckIn` ertesi gün / yerel gece yarısı (reddedildi, doğru), saatlik yaşam döngüsü, aynı gün çıkış 0 fiyat onayı, geç çıkış yüzde yuvarlaması (123.457 x %33,33 = 411,48), yetki matrisi (housekeeping geç çıkış reddi, `fees.nightReport` reception reddi).
4. `f.scn.ts`: rastgele işlem fuzz (60 tohum x 220 adım, 29 Şubat 2028 dahil; giriş/çıkış/tarih değiştirme/taşıma/oda değiştirme/iptal/gelmedi/geri alma/park/oda ekleme/ödeme/iade): geceler-kalemler eşleşmesi, durum tutarlılığı, saat çakışması, iade tavanı değişmezleri 0 ihlal.
5. `h.scn.ts`, `i.scn.ts`, `j.scn.ts`, `k.scn.ts`, `l.scn.ts`: bulgular 2, 5, 3, `freeRooms`/`hourlyCheck`/`roomsTaken` gece-içi doğrulama (doğru), bulgu 1.
6. Vitest (hepsi geçti): 24 servis dosyası (172 + 126 test), 29 renderer dosyası (257 test), `npm run i18n:check` (6149 anahtar, tr/en/ru eşit).
