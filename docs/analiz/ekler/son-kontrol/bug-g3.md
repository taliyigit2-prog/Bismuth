1. `g3-a` (4 test): her-N-konaklama sayaç/iptal (bulgu 1), dolu odayı kapatma ve çıkış sonrası (bulgu 2), çamaşır fişi/ad/tarih/kapanmış ay (8, 10, 11), kayıp eşya `[from,to)` ve dönüş tarihi (10).

4. `g3-e`: tedarik/kategori/ürün, oda arızası akışı, durum etiketleri, vardiya adı (8, 10).
5. Mevcut testler tek tek: `tasks-service, tasks-fixes, tasks-screens, staff-service, staff-fixes, shift-service, housekeeping-service, supply-laundry, supply-laundry-flows, contacts-lost-items` → 10 dosya, 91 test geçti. `npm run i18n:check` temiz.
