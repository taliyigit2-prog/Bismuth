## Nasıl çekildi

- `npm run build` sonrası `npm run ui:shot -- --full --wait 1200` (Türkçe) ve `--lang ru` (Rusça); masaüstü görüntüsü
  sayfanın tam yüksekliği, telefon görüntüsü tam sayfa (alt gezinme çubuğu görüntünün ortasında görünebilir; çekim
  yapıntısıdır).
- Kurulum sihirbazının 2.–8. adımları `/setup?step=N` ile çekilip tek görüntüde alt alta birleştirildi.
- İngilizce aynı anahtar kümesiyle çalışır (`npm run i18n:check`); görüntüsü pakete konmadı.
- Taşma denetimi otomatik: e2e testleri 1366×768 ve 390×844'te Türkçe ve Rusça bütün ekranlarda yatay taşma olmadığını
  doğrular.
