# Bismuth 1.0.1

## Yenilik

- **Kamera ekini kur…** düğmesi: kamera eki (`Bismuth-Kamera-Windows.zip`) artık klasör taşımadan, programın içinden
  kurulur. Kurulum sihirbazının Kamera adımında ya da **Ayarlar → Kamera**'da "Kamera eki kurulu değil" uyarısındaki
  düğmeye basıp zip dosyasını seçin; Bismuth eki açar, denetler ve kendini yeniden başlatır. Eski ek, yenisi sorunsuz
  kurulana kadar silinmez.

## Hangi dosyayı indireceğim?

| Bilgisayar | Dosya |
|---|---|
| Windows 10 / 11 (otel bilgisayarı ve çoğu bilgisayar) | `Bismuth-Setup.exe` |
| Windows, ARM işlemcili (az rastlanır) | `Bismuth-Setup-arm64.exe` |
| Mac, Apple çipli (M1, M2, M3, M4) | `Bismuth.dmg` |
| Mac, Intel işlemcili | `Bismuth-Intel.dmg` |

1.0.0 kuruluysa yeni kurulum dosyasını aynı şekilde çalıştırın; kayıtlarınız silinmez. Kurmadan önce
**Ayarlar → Yedek → Şimdi yedek al** düğmesine basmanız önerilir.

Kamera eki bu sayfada değildir: sahibin gizli "kamera" taslağındadır (`docs/otel/kurulum.md`, Kamera eki).
